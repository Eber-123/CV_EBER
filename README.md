# Portafolio web — Eber Pauccara Huancara

Todos los archivos de la web están en una sola carpeta para facilitar su publicación en GitHub Pages.

## Archivos principales
- `index.html`: página principal.
- `styles.css`: diseño, colores, adaptación móvil y efectos visuales.
- `script.js`: menú móvil, animaciones y fondo animado de conexiones.
- `favicon.svg`: icono del sitio.

## Fotografías, certificados y documentos
Las imágenes, certificados y el CV original están en la misma carpeta que `index.html`. No muevas ni renombres esos archivos porque el HTML los referencia directamente.

## Probar localmente
Abre `index.html` en Visual Studio Code con la extensión Live Server.

## Publicar en GitHub Pages
1. Crea un repositorio público.
2. Sube todos los archivos de esta carpeta directamente a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. Selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
5. Guarda. GitHub Pages generará la URL pública del portafolio.

## Código QR
Se ha incorporado la imagen QR que compartiste y se ha ampliado su presentación. El contenido del QR se mantiene sin modificar. Si deseas que dirija directamente al portafolio publicado, habrá que generar un QR nuevo con la URL definitiva.

## Nota
El archivo DOCX del CV se conserva como original. Los certificados de Scrum Foundation y Onshape, además de la constancia de participación como expositor (extraída de la página 6 del CV), se muestran en la sección de certificaciones. Las fotografías se han conectado a las secciones correspondientes.

## Mejoras de experiencia de usuario
- Tipografía ampliada y adaptable a pantallas pequeñas.
- Estados hover/focus con iluminación y elevación de tarjetas.
- Certificados en formato apaisado, con mayor área visible y acceso para ampliar.
- Panel gráfico de hitos y ruta de desarrollo. Los indicadores se basan en los logros publicados; las animaciones son decorativas y no representan mediciones automáticas.
- Menú que resalta la sección visible y controles accesibles por teclado.
